# Instrucciones para agentes de IA

## Contexto del proyecto
Desarrolla una landing page de una sola página sobre el artista Pablo Ruiz Picasso. El diseño debe ser sencillo, profesional y organizado.

## Tecnologías permitidas
- Utiliza exclusivamente HTML5 y CSS3.
- No utilices JavaScript, frameworks, bibliotecas ni otras tecnologías.
- Si una tarea parece requerir una tecnología prohibida, busca una alternativa compatible con HTML y CSS. No incorpores dependencias ni herramientas adicionales.

## Estructura de la página
La landing page debe incluir estas secciones, en este orden:
1. Bienvenida o portada.
2. Sobre mí.
3. Trayectoria artística.
4. Próximas presentaciones.

Incluye una barra de navegación con enlaces internos a las secciones correspondientes. Cada sección debe ocupar aproximadamente el alto de una pantalla de ordenador, permitiendo que su contenido se adapte con naturalidad a distintos tamaños de pantalla.

## Accesibilidad y SEO
- Utiliza elementos HTML semánticos y una jerarquía coherente de encabezados.
- Proporciona texto alternativo descriptivo para las imágenes informativas y texto alternativo vacío para las decorativas.
- Asegura que la navegación y los controles sean utilizables con teclado y comprensibles para lectores de pantalla.
- Incluye un título de página, una meta descripción y las etiquetas SEO básicas.
- Cuando corresponda, incorpora datos estructurados de Schema.org directamente en el HTML mediante microdatos o RDFa; no uses JavaScript ni bloques de script.

## Datos
Presenta información biográfica y artística factual y verificable sobre Pablo Ruiz Picasso; no inventes datos sobre su vida ni su trayectoria. La sección de próximas presentaciones debe tratar de exposiciones u otros eventos dedicados a su obra, no de apariciones personales del artista. Si no hay eventos reales confirmados, cualquier dato de ejemplo debe identificarse claramente como ficticio. Organiza la información para que pueda actualizarse fácilmente.

## Reglas generales
- Mantén el código limpio, sencillo y fácil de mantener.
- Respeta la estructura y el alcance de este proyecto.
- No añadas funcionalidades ni tecnologías que no se hayan solicitado.
- Limita cada cambio a los archivos necesarios para la tarea. No desarrolles la landing page si la tarea solo solicita modificar estas instrucciones.
