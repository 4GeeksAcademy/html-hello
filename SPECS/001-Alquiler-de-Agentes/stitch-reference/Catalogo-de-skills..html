¿Qué es una Skill en AgentHub?

ARQUITECTURA MODULAR

Una Skill es un módulo autónomo de ejecución (tool o capability encapsulada) que dota a un agente de acceso a APIs externas, herramientas de cálculo determinista, scraping o conectores blockchain. Las skills operan en contenedores aislados con control de cuotas y contratos inteligentes independientes.
