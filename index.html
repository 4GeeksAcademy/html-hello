¿Qué es una Skill en AgentHub?

Una skill es una capacidad encapsulada que amplía las funciones de un agente, por ejemplo, conectar con APIs, analizar riesgos o procesar datos. Los agentes pueden combinar varias skills según la tarea asignada.
