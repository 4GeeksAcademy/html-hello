# Project Brief — Rue de la Mode

> **Status:** Prototype · **Client:** Well-known French clothing brand  
> **Delivery:** Visual & functional prototype for client approval

---

## 1. Purpose

Build a **visual and functional prototype** of an online fashion store that demonstrates:

- Solid **SEO** practices (semantic HTML, Schema.org)
- A **modern, consistent** design language
- **Full responsiveness** across mobile, tablet, and desktop

---

## 2. Scope — 5 Views

| # | View | Description |
|---|------|-------------|
| 1 | **Home** | Brand landing page with hero, product highlights, and site navigation |
| 2 | **Catalog** | Filterable product grid (4×5) with category and size filters |
| 3 | **Product View** | Detail page: image, info, size/quantity selector, add-to-cart |
| 4 | **Cart** | Full-page cart with 3 sample products, summary, and checkout action |
| 5 | **Checkout** | 3-step payment form: personal → shipping → card |

---

## 3. Constraints

| Constraint | Detail |
|------------|--------|
| **Stack** | HTML + Tailwind CSS only. No React, JS frameworks, or backend |
| **Components** | Navbar and footer are **shared** across all views |
| **Navigation** | All pages must link to each other |
| **Prototype** | Static HTML (no live data, no server logic) |

---

## 4. Success Criteria

- [ ] Client can browse all 5 views
- [ ] Navigation flows naturally between pages
- [ ] Design feels cohesive and brand-aligned
- [ ] All pages render correctly on mobile, tablet, and desktop
